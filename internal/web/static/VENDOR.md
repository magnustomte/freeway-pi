# Vendored third-party files

Copied here rather than loaded from a CDN. The box has to work when the
internet does not, and a page that fetches code from elsewhere is a page whose
behaviour somebody else can change.

| File | Source | Version | Licence |
| --- | --- | --- | --- |
| `uplot.js` | [uPlot](https://github.com/leeoniya/uPlot) `dist/uPlot.iife.min.js` | 1.6.32 | MIT |
| `uplot.css` | uPlot `dist/uPlot.min.css` | 1.6.32 | MIT |

Fetched from `https://cdn.jsdelivr.net/npm/uplot@1.6.32/dist/`.

To update, replace both files and note the new version here. There is no build
step and nothing to rebuild.
